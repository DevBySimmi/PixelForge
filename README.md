🎨 PixelForge

PixelForge is a simple and lightweight desktop image editor built with Python and Pillow.

It provides useful image-editing features through an easy-to-use graphical interface.

✨ Features

- 📂 Open images
- ⚫ Convert images to grayscale
- 🔄 Rotate images
- 🌫️ Apply blur
- ☀️ Increase brightness
- 🌙 Decrease brightness
- 📐 Resize images
- 🔄 Reset edits
- 💾 Save edited images
- 🖥️ Simple desktop GUI

🛠️ Technologies

- 🐍 Python 3
- 🖼️ Pillow
- 🖥️ Tkinter

🚀 Installation

1. Open the project folder

cd PixelForge

2. Install Pillow

pip install pillow

3. Run PixelForge

python main.py

🖥️ How to Use

1. Open PixelForge.
2. Click Open and select an image.
3. Choose an editing option from the toolbar.
4. Use Reset if you want to undo all changes.
5. Click Save to export the edited image.
